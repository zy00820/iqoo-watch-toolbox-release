Install

三步装上手表

GT2 / GT / Watch 3 均运行蓝河操作系统，安装流程相同。

下载 rpk 到手机

按手表型号选包：GT2 下载标准包，GT 下载带 .gt 后缀的包，Watch 3 下载带 .w3 后缀的包，将 .rpk 保存到手机本地存储。装过 v1.0.x 旧版本请务必先卸载（v1.1.x 已更换为蓝河应用包格式）。

安装快应用调试器

在手机应用商店搜索并安装 快应用调试器（vivo 商店可搜）。

推送至手表

调试器 → 本地安装 → 选择 rpk → 推送到已配对的手表，手表上即刻出现工具箱。
