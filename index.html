Install

三步装上手表

iQOO Watch GT2 采用 vivo 手表快应用生态，安装流程如下。

下载 rpk 到手机

点击上方 Release 正式包 的加速链接，将 .rpk 安装包保存到手机本地存储。旧版本请先卸载。

安装快应用调试器

在手机应用商店搜索并安装 快应用调试器（vivo 商店可搜）。

推送至手表

调试器 → 本地安装 → 选择 rpk → 推送到已配对的 GT2，手表上即刻出现工具箱。
